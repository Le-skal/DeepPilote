Réentraînement ML Automatique
TTL Cache (6 heures)
Le modèle HMM est stocké en mémoire avec un cache TTL de 6h.
  • Après 6h → cache expire
  • Prochain appel → réentraînement
  • Environ 4 réentraînements/jour
cachetools.TTLCache(maxsize=1, ttl=21600)
Cold Start Render
Sur le free tier Render, le service dort après 15min d'inactivité.
  • Réveil → cache vide
  • Premier appel → réentraînement
  • ~30 sec de latence
cache_size: 0 au réveil
Données Utilisées
Le modèle utilise les 1500 derniers jours de données.
  • Prix ETF (8 tickers)
  • Indicateurs macro (VIX, spreads, yields)
  • Features calculées (z-scores, returns)
get_macro_data(days=1500)
Force Refresh
Endpoint pour forcer le réentraînement manuellement.
  • POST /api/v1/ml/refresh
  • Vide le cache
  • Prochain appel réentraîne
Rate limit: 2/minute
